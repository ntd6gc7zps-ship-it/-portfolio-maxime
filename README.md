# Portfolio Maxime + Mood.fm interactif

Décompresser le ZIP et déposer ce dossier sur Netlify Drop, avec `index.html` à la racine.

- Accueil portfolio : `/index.html`
- Étude de cas APWAP recadrée : `/projets/apwap.html`
- Mood.fm interactif : `/moodfm/index.html`

**Mood.fm** : 160 morceaux existants de 16 artistes, recommandés selon des profils d’ambiance illustratifs. Les indicateurs d’énergie et de tempo sont estimés et ne sont pas de véritables analyses audio. Les cartes affichent une photo des artistes lorsqu’elle est disponible via l’API de Wikipédia / Wikimedia Commons (nécessite une connexion Internet) ; quelques portraits ont des URL de repli vers Wikimedia Commons. Les morceaux sont reliés à une recherche Spotify externe, aucune lecture audio intégrée. Les curseurs réorganisent immédiatement les morceaux ; la liste entière est affichée sans ajout automatique au défilement pour éviter les sauts de mise en page. Le site existant sur chic-beijinho-f4d87a.netlify.app n’est pas modifié tant qu’il n’est pas redéployé.

Figma Mood.fm : https://www.figma.com/design/g96yqeT37djNqBjWl09TaW

Les images APWAP ont été recadrées pixel à pixel depuis les captures fournies et enregistrées en WebP qualité élevée. Le recadrage ne restaure pas les détails absents de la source.
